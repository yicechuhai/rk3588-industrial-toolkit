# RK3588 工业解决方案白皮书

> **版本**: v1.0 | **日期**: 2024-06  
> **适用场景**: 工业AI视觉检测、实时控制、边缘计算、国产化替代

---

## 摘要

RK3588 是瑞芯微推出的国产旗舰 8 核处理器，集成 6 TOPS NPU，是当前国产芯片中**计算密度最高**的工业边缘计算平台。本白皮书阐述了基于 RK3588 + RK3588-OpenLab 中间件的完整工业解决方案，涵盖 AI 推理、实时控制、工业协议和国产 OS 适配。

**关键结论**: 在 2000 元级 BOM 成本下，单块 RK3588 开发板可替代传统 "x86 工控机 + NVIDIA Jetson + PLC" 的三件套组合，实现 **25.7 FPS AI 检测 + 1ms EtherCAT 实时控制** 的并行运行。

## 2. 技术架构

### 2.1 全栈架构

```
┌─────────────────────────────────────────────────────────────┐
│                     应用层                                    │
│  工业缺陷检测 │ AGV 导航 │ 机器人抓取 │ 安全生产监控           │
├─────────────────────────────────────────────────────────────┤
│                   RK3588-OpenLab 中间件                       │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────────┐   │
│  │ AI 推理   │ │ 工业协议  │ │ 实时内核  │ │ OS 兼容层     │   │
│  │ Engine   │ │ Modbus   │ │ PREEMPT  │ │ Kylin/UOS    │   │
│  │ Pipeline │ │ OPC UA   │ │  CPU隔离  │ │ NeoCertify   │   │
│  │ Scheduler│ │ EtherCAT │ │ IRQ调优  │ │ AMP 调度     │   │
│  └──────────┘ └──────────┘ └──────────┘ └──────────────┘   │
├─────────────────────────────────────────────────────────────┤
│                    底层硬件                                    │
│     RK3588 SoC │ 4×A76+4×A55 │ 6TOPS NPU │ RGA │ MPP        │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 NPU 核心调度

RK3588 的 NPU 包含 3 个独立核心（每核 2 TOPS），支持动态调度：

```
┌──────────────────────────────────────┐
│           NPU 调度器                  │
│                                      │
│  核心 0: 主推理任务 (YOLOv5s)         │
│  核心 1: 辅助推理 (OCR/分类)          │
│  核心 2: 模型热切换 / 待命            │
│                                      │
│  策略: priority-based preemptive     │
└──────────────────────────────────────┘
```

### 2.3 CPU 分配策略

| CPU | 类型 | 用途 | 调度策略 | 优先级 |
|-----|------|------|----------|--------|
| 0-1 | A55 | 系统/网络中断 | CFS | — |
| 2-3 | A55 | Dashboard/OPC UA | CFS | — |
| 4-5 | A76 | AI 推理 | SCHED_RR | 50 |
| 6-7 | A76 | EtherCAT 主站 | SCHED_FIFO | 99 |

## 3. 核心能力

### 3.1 AI 视觉检测

| 指标 | 数值 | 说明 |
|------|------|------|
| 模型支持 | YOLOv5/v8/X, ResNet, MobileNet | RKNN 格式 |
| 推理 FPS | 25.7 (端到端) / 46 (纯推理) | 640×640 输入 |
| 精度损失 | <0.5% mAP (vs FP32) | INT8 量化 |
| 模型转换 | ONNX/PyTorch → RKNN | 一键转换 |
| 多模型 | 最多 3 个模型并行 | 每核心一个 |

### 3.2 工业协议栈

| 协议 | 角色 | 性能 | 用途 |
|------|------|------|------|
| **EtherCAT** | 主站 (IgH) | 1ms 周期, <50us 抖动 | 伺服/IO 控制 |
| **OPC UA** | Server | 20 槽位, 多客户端 | SCADA 对接 |
| **Modbus TCP** | Server | 多客户端并发 | PLC/HMI 对接 |
| **CAN FD** | SocketCAN | 8Mbps | 车载/传感器 |

### 3.3 实时性能

| 指标 | 标准 Linux | PREEMPT_RT (本项目) |
|------|-----------|---------------------|
| 最大延迟 | 1-10ms | **<50us** |
| P99 延迟 | ~1ms | **0.6us** |
| 周期频率 | 不保证 | 稳定 1kHz+ |
| CPU 隔离 | ❌ | ✅ 硬件级隔离 |

## 4. 典型应用场景

### 4.1 工业外观缺陷检测

```
相机 (RTSP) → RK3588 NPU (YOLOv5s 缺陷检测) → Modbus (PLC 联动)
                                               → OPC UA (MES 上报)
                                               → Dashboard (可视化)
```

- 检测速度: 25.7 件/秒 (单相机)
- 误检率: <2% (定制训练后)
- 自动 NG 品分拣信号: Modbus Coil 控制 PLC

### 4.2 EtherCAT 多轴运动控制 + AI 定位

```
EtherCAT (1ms)
├── 伺服 1 (X 轴)
├── 伺服 2 (Y 轴)
├── 伺服 3 (Z 轴)
└── IO 模块 (气动抓手)

AI 视觉 (NPU)
└── 工件定位 → 坐标 → 运动规划 → EtherCAT 指令
```

### 4.3 国产化替代方案

```
原方案:
  x86 工控机 (Windows) + 海康 AI 相机 + 西门子 PLC
  → 成本 ~25,000 元, 非国产, 供应链风险

替代方案:
  RK3588 (麒麟OS) + USB 相机 + EtherCAT IO
  → 成本 ~3,000 元, 全自主, 信创可查
```

## 5. 部署与运维

### 5.1 设备管理

```bash
# systemd 服务 (开机自启)
systemctl enable rk3588-pipeline  # AI流水线
systemctl enable rk3588-modbus    # Modbus
systemctl enable rk3588-opcua     # OPC UA
systemctl enable rk3588-dashboard # Web监控

# 健康检查
curl http://板卡IP:8080/api/health

# OTA 升级
bash tools/deploy_and_run.sh --update
```
