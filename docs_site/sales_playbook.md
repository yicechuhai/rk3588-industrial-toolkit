# 销售话术与客户转化流程

> 目标使用场景：与板卡商沟通、技术分享后的客户跟进、定向触达潜在付费用户

---

## 一、核心话术框架

### 1.1 价值主张（一句话版）

"我们帮你把 RK3588 上的 AI 视觉部署从 3 个月调到半天。不是卖软件，是帮你省掉反复试错的时间。"

### 1.2 客户痛点共鸣（5 秒破冰）

"你是不是也遇到过：
- NPU 驱动版本不匹配，重刷了 8 次镜像？
- 模型在 PC 上跑 50FPS，上板子只剩 12FPS？
- 摄像头→推理→OSD 这条流水线，CPU 吃满 400%？
- 老板问'能不能把检测结果发给 PLC'，你沉默了？

我们做了个开源工具链，正好解决这些问题。要不要花 5 分钟试试？"

### 1.3 技术信任建立（立旗三问）

1. **"RT 补丁影响 NPU 吗？"** → 不影响，NPU 是独立硬件。我们有实测数据。（甩 cyclictest + NPU 推理并行压测数据）
2. **"你们用 AMP 了吗？会不会有版权问题？"** → 不用。我们只用主线 PREEMPT_RT（6.12 已正式合入）。所有交付物是补丁脚本，你自己编译。
3. **"如果你们不干了怎么办？"** → 都是源码脚本 + YAML 配置，没加密。你的系统完全独立运行。

## 二、客户分层与转化策略

### A 层：付费种子用户（目标 10 人/年）

**画像**：已有 RK3588 项目在跑，遇到了具体的技术瓶颈，预算已批。

**触达方式**：
- GitHub Issues 中提过"模型部署失败"、"实时性不够"的大型 Issues → 主动私信提供帮助
- 电子发烧友直播后，在资料包里放"标准版 7 天试用申请链接"

**转化路径**：
1. 免费提供环境检测脚本 → 跑出来一份"你的环境有 3 个严重问题"的报告
2. 附上具体修复方案（其中 2 个标准版能自动修）
3. "标准版 ¥9,800/年，平均每天 27 块，比你的调试时间便宜多了"

### B 层：板卡商（合作方）

**画像**：淘宝/闲鱼 RK3588 工控板 TOP 20 卖家。

**触达方式**：
- 准备好"一键部署工具 + Demo"作为板卡赠品
- 联系话术："我在给你的客户减少技术咨询量。你的 RK3588 板子配上这个 AI 快速验证脚本，客户到手 5 分钟就能看到 YOLO 跑起来。减少了'板子买回去不会用'的退货和客服成本。"

**合作模式**：
- 板卡商在商品页放"AI 工业视觉快速验证包"下载链接（免费）
- 用户下载后 → 引导到 GitHub → 社区版免费 → 标准版 ¥9,800/年
- 板卡商每转化一个标准版客户，返 ¥1,500

### C 层：技术社区（流量池）

**画像**：CSDN、电子发烧友、知乎、掘金上关注嵌入式 AI 的开发者。

**触达内容节奏**：
| 时间 | 内容 | 平台 | 目标 |
|------|------|------|------|
| 第1周 | 立旗文章（RT调优记录） | CSDN + 电子发烧友 + 知乎 | 建立技术权威 |
| 第2周 | 零拷贝推理 Demo 视频 | B站 + 公众号 | 展示产品力 |
| 第3周 | "RK3588 NPU 驱动避坑指南" | CSDN + GitHub README | 长尾 SEO |
| 第4周 | 直播分享（电子发烧友） | 直播平台 | 第一次集中转化 |

## 三、定价与谈判策略

### 3.1 价格锚定

- 展示竞品对比："某系统集成商 RK3588 定制方案报价 15-25 万"
- 我们的 ¥9,800/年是竞品的 1/15-1/25
- "你付出的不是 ¥9,800，而是省下了至少 ¥5 万的人工调试成本"

### 3.2 常见异议处理

| 异议 | 回应 |
|------|------|
| "太贵了" | "你的人力成本一天多少？调试 RK3588 内核问题，三天能搞定吗？标准版 ¥9,800 ≈ 不到两天的工程师工资" |
| "我自己能调" | "当然可以。不过我们踩过的坑都在脚本里了——NPU 驱动版本对应关系、RT 补丁的 3 个常见崩溃点、摄像头 DMA-BUF 的内存泄漏修复……自己搞可能要一个月" |
| "能不能先免费试用" | "社区版永久免费。标准版提供 7 天全功能试用。用完之后你觉得值不值这个价，自己判断。" |
| "单位预算需要审批" | "给你准备一份《技术评估报告》模板，已经填好了性能测试数据和 ROI 计算。你拿去给领导审批就行。" |

### 3.3 企业版谈判要点

- 企业版 ¥29,800/年 核心卖点是"限次远程支持"
- 不要承诺无限制支持："5 次/年，每次 2 小时"
- 超出部分 ¥3,000/次（额外营收）
- 所有合同必须包含免责条款："不承担工业现场停机及间接损失"

监控客户活跃度：
- 连续 60 天未使用工具链 → 发送"我们优化了某功能"的邮件
- 发了 Issue 但 3 天未回复 → 主动跟进

- 连续订阅 2 年以上
- 曾提交 5+ 个 Issues
- 在沟通中提到"下一个项目要用另一个模型/协议"

## 五、法务合规清单

### 合同必备条款

```
1. 服务范围：仅限远程 Issue/邮件支持，不提供现场服务
2. 责任限制：不承担任何间接损失、连带损失或工业现场停机损失
3. 知识产权：客户拥有自己生成的模型和数据，我方拥有工具链源码
4. 不可抗力：硬件供应中断、原厂 SDK 变更不构成违约
5. 管辖：服务协议签订地法院
```

### 对外宣传的红线

- ❌ 绝不能说"保证实时性到 X μs" → 说"在我们的测试条件下达到 < 50μs"
- ❌ 绝不承诺"支持所有 RK3588 板卡" → 说"已验证以下板卡……其他板卡理论兼容"
- ❌ 绝不承诺"生产环境零故障" → 说"开发加速器，帮你 90% 的调优工作自动化"
- ❌ 不要改品牌名搭瑞芯微的便车 → 独立品牌，文档中明确"非瑞芯微官方产品"
